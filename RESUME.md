## PROJECTS

### 🏆 Hallucination Hunter · *Competition AI System*
**Role:** Core Contributor &nbsp;|&nbsp; **Stack:** Python · FAISS · BM25 · Cross-Encoder NLI · FastAPI · Streamlit  
**Link:** [github.com/Eleutherian13/hallucination-hunter](https://github.com/Eleutherian13/hallucination-hunter)

The flagship competition submission that earned a **top-4 national ranking** and an unsolicited *Judge's Favourite Code* distinction at the IIT Roorkee E-Summit DataForge track. This system addresses one of the most critical open challenges in the deployment of large language models: the detection and correction of hallucinated claims.

**Architecture & Technical Highlights:**
- **Hybrid Retrieval Pipeline:** Combines FAISS-based dense semantic vector retrieval with BM25 sparse lexical retrieval, forming a robust ensemble that captures both conceptual similarity and precise keyword-level evidence — effectively outperforming single-modality retrieval baselines.
- **NLI Cross-Encoder Verification:** Retrieved evidence passages are passed through a Natural Language Inference (NLI) cross-encoder model to perform fine-grained entailment-based claim verification, distinguishing factual statements from hallucinated ones with high precision.
- **Production-Grade Deployment:** Complete system delivered with a FastAPI backend for scalable inference serving and an interactive Streamlit frontend for real-time demonstration.
- **Benchmark Performance:** Achieved an **F1 Score of 0.89+** on evaluation benchmarks, placing it in the top tier of all competition submissions.

### 💡 Explainable RAG · *Transparent AI Pipeline*
**Role:** Key Contributor &nbsp;|&nbsp; **Stack:** Python · LangChain · FAISS · NLP  
**Links:** [Explainable-Rag](https://github.com/Eleutherian13/Explainable-Rag) · [Explainable-Rag-v2](https://github.com/Eleutherian13/Explainable-Rag-v2)

A Retrieval-Augmented Generation system engineered around a single, principled conviction: *an AI that cannot explain itself should not be trusted*. This project moves beyond the typical RAG paradigm of "retrieve and generate" to expose the complete reasoning apparatus to the end user.

**Key Features:**
- **Full Document Lineage Attribution:** Every generated answer is accompanied by precise citations linking claims to their originating source documents — eliminating the "black box" problem endemic to most LLM deployments.
- **Reasoning Chain Exposure:** The chain-of-thought reasoning process is surfaced directly within the interface, giving users an auditable trail from question to answer.
- **Per-Answer Confidence Scoring:** Each response is annotated with a quantitative confidence score, enabling downstream trust calibration and flagging of uncertain outputs.
- **v2 — Real-Time Web Interface:** The second iteration elevates the system to a full web-based application with a React frontend and Node.js backend, enabling real-time interactive explainability for non-technical users.
